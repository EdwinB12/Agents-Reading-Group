# Research notes

Background material gathered on 18 October 2026 while preparing the
[Mathpocalypse session](../README.md). These notes are working notes, not reading for attendees;
the reading list is in the [session plan](../README.md#background-reading).

The story is still moving and many figures are contested. Each note says which claims were checked
against primary sources. Where counts differ, use the [`openai/math` README](https://github.com/openai/math)
figures (see the research brief, §8).
